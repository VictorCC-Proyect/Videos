# Seis Cuerdas — app para aprender guitarra acústica

Abre `index.html` en Chrome, Edge o Safari para usarla con micrófono
(detector de acordes y afinador). `app.html` es la misma app en la versión
que se publica como página de claude.ai.

Después de editar `app.html`, corre `./build.sh` para regenerar `index.html`.

Secciones: Acordes (12 notas × 16 tipos, diagramas, pasos, sonido, comprobación
con micrófono), Afinador, Círculo de quintas, Lecciones, Cambios rápidos,
Ritmo y progresiones, Oído, Teoría (diapasón) y Mi rutina.
